# Get Started

Requires Python 3.11+.

```bash
# 1. Clone the repo
git clone https://github.com/williamhuybui/cockroach-survivor-learn.git
cd cockroach-survivor-learn

# 2. Create a virtual environment (first time only)
python3 -m venv .venv

# 3. Turn it on
source .venv/bin/activate        # macOS/Linux
.venv\Scripts\activate           # Windows

# 4. Install dependencies
pip install -r requirements.txt

# 5. Turn it off when you're done
deactivate
```

Your terminal prompt shows `(.venv)` while the environment is on. Turn it on again each time you open a new terminal. In VS Code, select the `.venv` interpreter/kernel before running notebooks.
